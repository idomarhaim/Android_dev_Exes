# Changes — 18/06/2026

> **Branch:** `Ex2`

HW2 — major expansion of the HW1 racing game: menu screen, three control
modes, a wider/longer road with coins and an odometer, tilt-sensor control,
a crash sound, and a high-scores screen (table + map fragments) backed by
Room and the device location.

## 🆕 New Features

- **Menu screen** (`MenuActivity`, now the launcher): three game modes
  (Buttons–Slow, Buttons–Fast, Tilt Sensor) plus a link to High Scores.
- **Wider + longer road**: 5 lanes × 16 rows (was 3 × 12).
- **Coins on the road**: collectible coins spawn alongside obstacles; each is
  worth a `COIN_BONUS` toward the score and plays a pickup tone.
- **Odometer**: live distance counter, plus a coins counter, in the HUD.
- **Tilt-sensor control**: accelerometer steers the car left/right in Sensor
  mode. **Bonus** — tilting forward/back changes the scroll speed.
- **Crash sound**: short tone via `ToneGenerator` (no audio asset needed),
  in addition to the existing vibration + toast.
- **High-scores screen** (`HighScoresActivity`) with **two fragments**:
  - `ScoresTableFragment` — RecyclerView of the **top-ten** scores since
    install (Room query `ORDER BY score DESC LIMIT 10`).
  - `ScoresMapFragment` — Google Map with a marker per score location;
    tapping a table row re-centres the map (shared `HighScoresViewModel`).
- **Score = distance + coins × bonus**, persisted with the device location
  captured at game over.
- **App icon**: custom `ic_launcher_game` vector (road + car).

## 🔧 Technical Changes

- **Package / namespace** renamed `com.example.hw1` → `com.example.hw2`
  (applicationId, versionCode 2 / versionName 2.0). Root Gradle project name
  stays `HW1`.
- **Pure-logic extraction**: game state moved into `GameEngine` (no Android
  deps) so it is JVM-unit-testable; `GameActivity` only renders it. Movement
  model unchanged (visibility toggling — no Canvas / translationX-Y).
- **Room** persistence: `HighScore` entity, `HighScoreDao`, `AppDatabase`,
  `HighScoreRepository` (kotlin-kapt added).
- **Google Maps + FusedLocation**: `play-services-maps`, `play-services-location`.
  Maps key read from `local.properties` (`MAPS_API_KEY`) via a manifest
  placeholder; falls back to `YOUR_API_KEY_HERE` so the project still builds.
- New permissions: `INTERNET`, `ACCESS_FINE/COARSE_LOCATION` (runtime request).
- Added deps: constraintlayout, recyclerview, fragment-ktx, lifecycle
  (viewmodel/livedata/runtime), activity-ktx, coroutines.
