# Changes — 20/06/2026

> **Branch:** `Ex2`

## Round 1 — High-scores screen

Fixes reported from device testing: map markers not visible and poor contrast
on the selected row.

## 🔧 Bug Fixes

- **Selected-row contrast** (white-on-yellow → unreadable): row text colours
  are now set per state in `ScoresAdapter` — light text on the normal dark
  row, dark text on the highlighted yellow selected row — so both stay legible.
  Highlight colour tweaked to `#FFF176`.
- **Map markers / camera**: `ScoresMapFragment` now frames *all* located scores
  via `LatLngBounds` (with a single-marker zoom fallback) instead of only
  centring on the first one, so every recorded location is visible at once.
- **More reliable location capture**: on game over `GameActivity` falls back to
  `getCurrentLocation(PRIORITY_BALANCED_POWER_ACCURACY, …)` when
  `lastLocation` is null (common right after boot / on some devices), so newly
  recorded scores actually carry coordinates and show up on the map.

## ⚠️ Configuration note (root cause of the blank map)

The map renders blank/grey when the **Google Maps API key is missing**. The
build currently injects the placeholder `YOUR_API_KEY_HERE` (seen in the merged
manifest), which fails authentication, so no tiles or markers appear. Put a
real key in `local.properties`:

```
MAPS_API_KEY=AIza...your_real_key...
```

then rebuild. Existing scores saved before the location fix have no
coordinates and won't get markers; play a new game (with location permission
granted) to record located scores.

## Round 2 — Sensor-mode controls

Two tilt-control fixes for Sensor mode.

### 🔧 Bug Fixes

- **Speed direction inverted**: tilting the phone **forward** now speeds the car
  up (objects approach faster) and tilting **back** slows it down. The speed
  factor's `y` coefficient flipped from `+` to `-`
  (`1 - (y / GRAVITY) * 0.8`).
- **One lane per tilt**: steering is now edge-triggered with hysteresis instead
  of a 220 ms repeat. The car steps a single lane when the tilt crosses
  `TILT_THRESHOLD` (3.0), and won't move again until the phone returns below
  `TILT_RELEASE` (1.5). A single tilt no longer skips 2+ lanes.

### 📁 Modified Files

- `GameActivity.kt` — inverted speed sign; replaced time-cooldown steering with
  an armed/release hysteresis guard (`tiltArmed`, `TILT_THRESHOLD`,
  `TILT_RELEASE`); removed `lastTiltMoveMs` / `TILT_COOLDOWN_MS`.

### 🧪 Tests

- Tilt logic depends on live accelerometer input, so it isn't covered by the
  JVM `GameEngineTest`; verified by `get_errors` (no compile errors) and
  on-device testing. The underlying `moveCar` lane-clamping it calls *is*
  unit-tested.
