# Changes — 26/05/2026

## 🆕 New Features

- 🏁 **HW1 — Endless 3-Lane Obstacle Racing Game** scaffolded from scratch:
  - Three-lane road built with a `FrameLayout` "game area" inside a
    `ConstraintLayout` root.
  - Player car positioned via `translationX` / `translationY` (no `Canvas`,
    per the assignment).
  - Left / right arrow `ImageButton`s switch the car between lanes with a
    short animation.
  - Obstacles spawn at the top in a random lane every ~0.9 s and scroll down
    at constant speed on a `Handler` game loop.
  - Collision detection (same lane + vertical overlap) triggers a crash:
    `Toast` notification + ~250 ms device vibration.
  - Three hearts in the top-right show the remaining lives; hearts are
    hidden as lives are lost.
  - When all 3 lives are lost the game resets lives and continues — endless.
  - Activity locked to portrait orientation.

## 🔧 Technical Changes

- Build configured with **AGP 8.5.2**, **Kotlin 1.9.24**, **compileSdk 34**,
  **minSdk 24**, **Java 17**, View Binding enabled.
- Single dependency stack: AndroidX Core, AppCompat, Material, ConstraintLayout.
- `android.permission.VIBRATE` declared in the manifest for crash feedback.
- Game loop implemented with `Handler.postDelayed` on the main `Looper`;
  start/stop tied to `onResume` / `onPause`.
- All game-object positioning uses `View#translationX` / `View#translationY`
  — no `Canvas`, no `SurfaceView`, no custom `onDraw`.
